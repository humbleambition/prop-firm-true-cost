# Prop Firm True Cost

Independent comparison of prop-firm plans by true cost to get funded (checkout price with current code + activation + fees). Not financial advice; always verify on the firm's own site.

- `site/` static app (index.html, base.json data, refresh.py daily code check)
- `setup-vps.sh` one-time server setup; `update.sh` daily pull + refresh

Seed data partly from TradingLookup open data, CC BY 4.0.
